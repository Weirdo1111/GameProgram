# Audio Sources

All imported sound effects listed below were downloaded from [GamerSounds](https://gamersounds.com/).

GamerSounds provides these resources free for personal learning and communication, matching this course project's use.

## Imported Sound Effects

- `Assets/Resources/Audio/background_music.mp3`
  - Original file: `未来科幻.mp3`
  - Used for: looping background music from game startup.
- `Assets/Resources/Audio/normal_attack.mp3`
  - Original file: `火球.mp3`
  - Used for: Magic Bolt normal attacks.
- `Assets/Resources/Audio/fire_tornado.mp3`
  - Original file: `火焰旋风.mp3`
  - Used for: Ultimate Storm's tornado skill.
- `Assets/Resources/Audio/fire_bomb.mp3`
  - Original file: `火焰魔法.mp3`
  - Used for: Fire Zone bomb throws.
- `Assets/Resources/Audio/enemy_death.mp3`

  - Used for: one of two randomly selected rewarded enemy-death sounds.
- `Assets/Resources/Audio/enemy_death_alt.mp3`
