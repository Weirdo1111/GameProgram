Zombie Storm - Game Asset Source Reference
Last updated: 2026-06-09

This file consolidates the known sources for visual/game art assets used by the
Zombie Storm Unity prototype. License notes reflect the source files and project
documentation currently present in the repository. Re-check the original source
pages before publishing raw asset files or making a commercial release.
