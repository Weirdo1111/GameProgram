## CraftPix Reaper Zombie

- Source pack: `Free Zombie Villager Chibi Character Sprites`, `Zombie_Villager_1`
- Source site: https://craftpix.net/
- License reference: https://craftpix.net/file-licenses/
- Imported prototype role: `Reaper`, a long-reach sweeping melee zombie.

Imported animation folders:

- `Run`: movement loop, 12 frames.
- `Slash`: readable standing sweep attack, 12 frames.
- `RunSlash`: reserved moving-sweep animation, 12 frames.
- `Hurt`: hit reaction, 12 frames.
- `Death`: death animation, 15 frames.

The first gameplay pass uses the standing sweep because its long attack arc gives the player a readable warning. `RunSlash` is retained for a later telegraphed dash variation.
