## CraftPix Zombie Villager

- Source pack: `Free Zombie Villager Chibi Character Sprites`
- Source site: https://craftpix.net/
- License reference: https://craftpix.net/file-licenses/
- Imported prototype role: `Slasher`, a sword-wielding melee zombie.

Imported animation folders:

- `Run`: movement loop, 12 frames.
- `Slash`: melee attack with built-in sword arc, 12 frames.
- `Hurt`: hit reaction, 12 frames.
- `Death`: death animation, 15 frames.

Only the PNG sequences needed for the first gameplay integration are copied here. The original pack also contains throw and air-action animations suitable for a later ranged enemy variant.
